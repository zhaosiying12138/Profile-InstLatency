## Reverse-engineering an LLVM RISC-V vector scheduling model from cycle-level gem5 profiling

**Pipeline**: minimal priors → designer micro-op parameter space (`config/yushuxin_timing_v2.yaml`) → injection into gem5 v24.1.0.3 MinorCPU via a **pure-config FU pool** (no simulator source patches) → tick-exactness gate (`verify_timing_exactness.py`, design invariants asserted per cycle) → differential experiment suite **E0–E11** (streams / RAW chains / cross-class matrix / WAW / WAR / mixed streams / issue probes / loads / composite) → closed-form inversion (`profile_final.py`, three-state verdicts) → LLVM `RISCVSchedYuShuXinV2.td` → **llvm-mca closure** → end-to-end A/B case study.

**The decisive mechanism finding** (why injection is non-negotiable): gem5 v24.1.0.3's default MinorCPU FU pool routes **every** vector OpClass (SimdAdd/SimdMult/SimdDiv/SimdCmp/…) into one `MinorDefaultFloatSimdFU` with `opLat=6`, `srcRegsRelativeLats=[2]`, `issueLat=1`. The observable RAW latency is `opLat − srcRegsRelativeLats = 4` for *every* vector instruction — profiling a default MinorCPU measures the defaults, not a machine. MinorFU's knobs (`opLat`, `issueLat` (=opLat ⇒ non-pipelined), `srcRegsRelativeLats` (bypass depth / WAR release / cross-pipe penalty), `cantForwardFromFUIndices` (cross-pipe no-forward), `extraCommitLat` (WAW spacing)) map one-to-one onto everything we need, so a config-only injection suffices.

**Machine under test** (fictitious in-order dual-issue RV64, VLEN=256, SEW=e32, LMUL m1/m2/m4): two 1-wide vector pipes, non-pipelined divider (R≡L), no vector renaming, latency = fixed + LMUL-proportional part. **54 unknowns** = 6 global knobs + 8 instruction classes × 6 per-class knobs.

**Complete ground truth** (design values generated by `python3 scripts/yxmodel.py`; measured column from `results/profile_measured.json`; bold = emergent, landed as measured):

| instruction | pipe | pipelined | L(B,K) | L@λ=1/2/4 | R design@1/2/4 | R measured@1/2/4 | WAW spacing@m1/m2/m4 | read_lat |
|---|---|---|---|---|---|---|---|---|
| vadd.vv | VP0 | ✓ | (2,1) | 3/4/6 | 1/2/4 | 1/2/4 | 6/7/9 | 3 |
| vmul.vv | ANY | ✓ | (3,1) | 4/5/7 | 1/2/4 | **1/1/2** | 6/7/9 | 2 |
| vdivu.vv | VP1 | ✗ | 12·λ | 12/24/48 | R≡L | 12/24/48 | 12/24/48 | 2 |
| vmseq.vv | VP0 | ✓ | (1,1) | 2/3/5 | 1/2/4 | **4/5/7** | 6/7/9 | 4 |
| vredsum.vs | VP1 | ✓ | (4,2) | 6/8/12 | 2/4/8 | 2/4/8 | 8/10/14 | 2 |
| vslideup.vx | VP0 | ✓ | (2,2) | 4/6/10 | 2/4/8 | **4/7/18** | 6/8/12 | 2 |
| vcpop.m | VP0 | ✓ | (3,0) | 3/3/3 | 1/1/1 | 1/1/1 | 6/6/6 | 3 |
| viota.m | VP0 | ✓ | (4,1) | 5/6/8 | 1/2/4 | **1 / 5⁄4 / 5⁄2** | 6/7/9 | 1 |

Emergence mechanisms: vmul = ANY dual-slot (⌈λ/2⌉), vmseq = vmask_mv companion cadence, vslideup = non-affine PERM cadence, viota = μop co-issue (fractional throughput; landed as conservative integer λ, documented). Distinctness by construction: all eight (B,K) pairs differ; vmul/vslideup collide at L=4@λ=1 (separated by slope) and vredsum/vslideup share R slope 2 (separated by L).

**Differential experiment matrix** (every unknown ← the experiment that recovers it):

| experiment | differential design | recovers |
|---|---|---|
| E2 stream N-scan | rotating dests, slope+intercept | R(B,K); slope R≡L ⇒ non-pipelined |
| E3 self-RAW chain | dest=src, N-scan | same-pipe L(B,K) |
| E4 cross-class matrix | 8×8 producer×consumer + k filler sweep, control twin = consumer reads independent reg | bypass matrix, G3/G4, L of non-chainable classes |
| E5 WAW pair | same-dest double write, d-sweep + different-dest control | waw_extra (measured ≤1 cycle) |
| E6 WAR pair | reader→writer d-sweep + control | read_lat (measured ≈0 extra) |
| E7 mixed streams | interleaved vs separate-sum | pipe partition (sum=other-pipe; serial=same; partial=ANY) |
| E8 issue probes | scalar+vector, cross-pipe pair, triple | IssueWidth=2 (3 falsified), SingleIssue=false |
| E9 λ-sweep | E2–E6 × {m1,m2,m4}; two points fix (B,K), third checks residual 0 | all linear coefficients |
| E10 loads | warmed vle32 + consumer; back-to-back loads | LoadLatency=4; VLSU 1 beat/group |
| E11 composite | multi-segment single program | whole-model cross-validation (5/5) |

**Headline results**
- Tick gate `ok=23 bad=0`; E11 composite additivity `5/5 PASS`.
- ~1900 real gem5 traces inverted with three-state verdicts (`exact_fit` / `bounded` / `non_identifiable` = 0); emergent cadences (vmul ANY, vmseq companion, vslideup non-affine, viota fractional 5/4 & 5/2) profiled and landed as measured.
- 1185 control-paired E5/E6 runs: WAW ≤1 cycle, WAR ≈0 → **fused into ReleaseAtCycles** (documented, not hidden).
- llvm-mca `-instruction-tables` on `-mcpu=YuShuXinV2`: vdivu RThru 12.00 (non-pipelined), vmul 0.50 (dual-slot ProcResGroup), `Dispatch Width: 2`; cross-pipe no-bypass encoded as **negative ReadAdvance**.
- **End-to-end A/B**: same hand-written RVV-intrinsic program, model vs generic-rv64 — order rewrites (fillers ride the 12-cycle divide bubbles), gem5 **125 vs 132 cycles (+5.3%)**, llvm-mca delta **exactly 7 cycles == gem5 delta**; `--timeline` shows dual-pipe overlap. One command: `bash scripts/build_demo.sh`.

## 基于 gem5 周期级差分实验反演 LLVM RISC-V 向量调度模型（v2 全量重做）

**流程**：少量先验 → 设计者微操作参数空间（`config/yushuxin_timing_v2.yaml` 单一真值源）→ **纯配置**注入 gem5 v24.1.0.3 MinorCPU（零模拟器源码补丁）→ tick 精确一致性门禁 → **E0–E11 差分实验套件** → 闭式反演（三态判定）→ LLVM `RISCVSchedYuShuXinV2.td` → **llvm-mca 闭合验证** → 端到端 A/B 综合测试。

**决定性的机制发现**（为什么必须先注入）：gem5 v24.1.0.3 MinorCPU 的默认 FU 池把**全部**向量 OpClass（SimdAdd/SimdMult/SimdDiv/SimdCmp/…）路由到同一个 `MinorDefaultFloatSimdFU`，`opLat=6`、`srcRegsRelativeLats=[2]`、`issueLat=1`——可观测 RAW 延迟恒为 `6−2=4`，与指令种类/LMUL/流水性全无关。**不注入直接 profile，测到的只是默认参数的回声。** 而 MinorFU 的旋钮（`opLat`、`issueLat`（=opLat 即非流水）、`srcRegsRelativeLats`（旁路深度/WAR 释放/跨管罚）、`cantForwardFromFUIndices`（跨管禁前递）、`extraCommitLat`（WAW 间距））与我们需要的物理量一一对应——纯配置注入即可。

**被测机器**（假想按序双发射 RV64，VLEN=256、SEW=e32、LMUL m1/m2/m4）：双 1 宽向量管线、非流水除法器（R≡L）、无向量重命名、延迟=固定+∝LMUL。**54 个未知量** = 6 个全局旋钮 + 8 指令类 × 6 个每类旋钮。

**完整地面真值表**（设计值由 `python3 scripts/yxmodel.py` 生成，实测列出自 `results/profile_measured.json`；加粗=涌现，按实测落表）：

| 指令 | 管线 | 流水 | L(B,K) | L@λ=1/2/4 | R设计@1/2/4 | R实测@1/2/4 | WAW间距@m1/m2/m4 | read_lat |
|---|---|---|---|---|---|---|---|---|
| vadd.vv | VP0 | ✓ | (2,1) | 3/4/6 | 1/2/4 | 1/2/4 | 6/7/9 | 3 |
| vmul.vv | ANY | ✓ | (3,1) | 4/5/7 | 1/2/4 | **1/1/2** | 6/7/9 | 2 |
| vdivu.vv | VP1 | ✗ | 12·λ | 12/24/48 | R≡L | 12/24/48 | 12/24/48 | 2 |
| vmseq.vv | VP0 | ✓ | (1,1) | 2/3/5 | 1/2/4 | **4/5/7** | 6/7/9 | 4 |
| vredsum.vs | VP1 | ✓ | (4,2) | 6/8/12 | 2/4/8 | 2/4/8 | 8/10/14 | 2 |
| vslideup.vx | VP0 | ✓ | (2,2) | 4/6/10 | 2/4/8 | **4/7/18** | 6/8/12 | 2 |
| vcpop.m | VP0 | ✓ | (3,0) | 3/3/3 | 1/1/1 | 1/1/1 | 6/6/6 | 3 |
| viota.m | VP0 | ✓ | (4,1) | 5/6/8 | 1/2/4 | **1 / 5⁄4 / 5⁄2** | 6/7/9 | 1 |

涌现机制：vmul=ANY 双槽（⌈λ/2⌉）、vmseq=vmask_mv 伴随节奏、vslideup=非仿生 PERM 节律、viota=μop 同拍共发（分数吞吐；落保守整数 λ 并注释声明）。可区分性设计：8 类 (B,K) 两两不同；vmul/vslideup 在 λ=1 撞 L=4（靠斜率分离）、vredsum/vslideup 同 R 斜率 2（靠 L 维分离）。

**差分实验矩阵**（每个未知量 ← 恢复它的实验）：

| 实验 | 差分设计 | 恢复 |
|---|---|---|
| E2 独立流 N 扫描 | 目的轮转，斜率+截距 | R(B,K)；R≡L 大斜率 ⇒ 非流水判别 |
| E3 自 RAW 链 | dest=src，N 扫描 | 同管 L(B,K) |
| E4 跨类 RAW 矩阵 | 8×8 生产者×消费者 + k 填充扫描，对照组=消费者改读独立寄存器 | 旁路矩阵、G3/G4、不可自链类的 L |
| E5 WAW 对 | 同目的两写 d 扫描 + 写异寄存器对照 | waw_extra（实测 ≤1 拍） |
| E6 WAR 对 | 读者→写者 d 扫描 + 对照 | read_lat（实测 ≈0 额外停顿） |
| E7 混合流 | 交错 vs 分跑相加 | 管线划分（和=异管；串=同管；部分=ANY） |
| E8 发射宽探测 | 标量+向量、异管对、三联 | IssueWidth=2（证伪 ≥3）、SingleIssue=false |
| E9 λ 扫描 | E2–E6 × {m1,m2,m4}，两点定系数、第三点验残差 0 | 全部线性系数 |
| E10 访存 | 预热 load + 消费者；连续 load | LoadLatency=4；VLSU 1 beat/组 |
| E11 复合可加性 | 单程序多分段 | 全模型交叉验证（5/5） |

**要点结果**
- 门禁 `ok=23 bad=0`；E11 复合可加性 `5/5 PASS`；
- 约 1900 条真实 trace 三态反演（exact_fit / bounded / non_identifiable=0）；涌现节律（vmul 双槽、vmseq 伴随、vslideup 非仿生、viota 分数 5⁄4 与 5⁄2）按实测落表；
- 1185 对 E5/E6 配对实测：WAW≤1 拍、WAR≈0 → **融合进 ReleaseAtCycles**（如实记录的融合证据）；
- llvm-mca：vdivu 12.00（非流水）、vmul 0.50（双槽 ProcResGroup）、Dispatch Width 2；跨管无旁路以**负 ReadAdvance** 表达；
- **端到端 A/B**：同一手写 RVV intrinsic 程序，`llc -mcpu=YuShuXinV2` vs `generic-rv64`——顺序重排可见（填充进 12 拍除法气泡），gem5 实测 **125 vs 132 周期（+5.3%）**，llvm-mca 用同一模型预测差值**恰为 7 拍、与实测精确对齐**，`--timeline` 可视化双管 overlap。一条命令：`bash scripts/build_demo.sh`。
